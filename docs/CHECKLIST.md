# 爱迦租车发版上线全要素自检清单 (Release & Deployment Checklist)

为确保爱迦租车小程序在正式提审与全量发布时的稳定性、合规性与极致性能，发版负责人必须在发布前逐项核对并确认本清单。

---

## 1. 代码质量与自动化门禁 (Engineering Quality Gate)

- [ ] **执行全量工程质量门禁**：
  ```bash
  node scripts/qualityGate.js
  ```
  - [ ] 阶段 1: 项目目录与页面声明规范通过
  - [ ] 阶段 2: 敏感密钥与私有凭据扫描 100% 洁净
  - [ ] 阶段 3: 5 篇官方精选攻略草稿 Schema 校验通过
  - [ ] 阶段 4: 16 个数据库集合安全规则与 52 个索引清单核验通过
  - [ ] 阶段 5: 56 个云函数架构规范与安全鉴权审计通过（0 个非预期公开漏洞）
  - [ ] 阶段 6: 小程序主包体积严格在安全警戒线（<= 1.75 MiB）以内
  - [ ] 阶段 7: Jest 当前全部测试套件通过，记录实际套件数、用例数并核对测试日志
  - [ ] 阶段 8: 无头全页面组件交互仿真全部通过，记录实际点击断言数
  - [ ] 阶段 9: 图片预加载与缓存恢复仿真通过（7 个场景、30 项断言）
  - [ ] 自动化结果与后续真机验收分别记录；图片与缓存仿真不代表多角色预约业务已完成真机验收

- [ ] **代码发布洁癖检验 (Release Hygiene)**：
  - [ ] 确认客户端与云端生产代码中无任何未捕获的 `console.log`、`console.info` 或 `debugger`。

---

## 2. 小程序包体积与分包隔离 (Package Budget)

- [ ] **主包体积控制**：
  - [ ] 当前真实主包 <= 1.75 MiB（硬性物理上限 2.0 MiB）。
  - [ ] 静态图片资源中单张未压缩文件不得超过 100 KB。
- [ ] **分包独立性**：
  - [ ] 所有管理端功能集中在 `pages-admin` 分包，确保普通用户首次冷启动时只下载纯净 C 端主包。
  - [ ] `app.json` 中配置了必要的 `preloadRule`（仅在进入会员中心时按需预载管理端）。

---

## 3. 法律合规与隐私保护 (PIPL & Legal Compliance)

- [ ] **隐私政策与授权弹窗**：
  - [ ] 微信官方《小程序用户隐私保护指引》已在微信公众平台后台完成更新与同步。
  - [ ] 个人信息申请入口（`pages/privacy-request/privacy-request`）正常可用，支持用户发起“个人信息查询”、“信息更正”与“注销删除”申请。
  - [ ] 管理端隐私处理后台（`pages-admin/privacy-request-manage`）具备完备的处理与凭证归档能力。
- [ ] **租赁免责与平台规则**：
  - [ ] 平台规则页面（`pages/content-page?type=rules`）明示押金、违章代缴、划痕定损与商业保险责任边界。

---

## 4. 腾讯云开发与数据库环境 (CloudBase Environment)

- [ ] **环境隔离**：
  - [ ] 确认已将客户端连接的环境 ID 切换至生产环境（非开发/测试环境）。
- [ ] **集合权限与安全规则**：
  - [ ] 16 个业务集合已在云开发控制台导入安全规则（参照 `cloudfunctions/common/security-rules/manifest.json`）。
  - [ ] 严禁客户端未经云函数授权直接写入关键系统集合（如 `roles`, `app_configs`, `audit_logs`）。
- [ ] **数据库索引**：
  - [ ] 生产数据库中已全部创建建议的 31 条核心复合索引与 4 条唯一索引（如 `roles.openid`, `vehicles.plateNumber`, `app_configs.key`）。

---

## 5. 微信公众平台后台配置 (MP Dashboard Settings)

- [ ] **服务器与网络域名**：
  - [ ] 若有第三方地图或图片存储域名，已在“开发管理 -> 开发设置 -> 服务器域名”配置合法白名单。
- [ ] **企业微信客服 (WX KF)**：
  - [ ] 在运营配置中确认已填写正确的企业 ID (`wxKfCorpId`) 与客服链接 (`wxKfExtInfo`)，测试真机唤起企业微信原生客服无异常。
  - [ ] 清空客服电话后，返回收藏和车辆详情并刷新配置，复制内容、咨询入口及新生成海报均不再使用旧号码；客服会话的迟到失败也不得恢复旧号码。
  - [ ] 配置加载或保存收到异常响应时，未保存草稿与配置版本仍保留，不显示保存成功。
- [ ] **订阅消息模板**：
  - [ ] 确认已配置正确的“预约状态更新通知”模板 ID，并在详情页点击允许接收通知测试正常。
  - [ ] 超长或错误类型的客服电话、订阅模板 ID 被明确拒绝，不能截断后保存；旧客户端省略字段保留已有值，显式空串可以清空。

## 6. 提审与灰度发布策略 (Release Rollout)

- [ ] **体验版全量实机验证**：
  - [ ] 组织内部测试人员使用 iOS（iPhone 13 以上，支持灵动岛与底部安全区）及 Android（各主流厂商旗舰）真机进行全流程扫码实测。
  - [ ] 验证弱网、飞行模式重连、息屏重入等边缘场景下的优雅恢复。
  - [ ] 车辆详情带入 7 天、预约快捷安排 3 天时，起止日期与显示天数一致；取车网点改名后仍选择原网点，请求期间换城市或网点不被旧选择覆盖。
  - [ ] 保留报价草稿时保存备注或协调安排，界面立即显示服务端结果，随后保存使用新基线；两名顾问修改同一客户标签时明确提示冲突，不覆盖他人结果。
  - [ ] 日历集合、环境或权限配置异常时，客户端提示档期查询失败；非法类型价格不能保存，也不能流入客户参考费用。
  - [ ] 同用户、同车、同日期用不同请求标识并发提交时只创建一笔有效预约；同请求重试返回原订单，事务重查失败时不新增订单。
  - [ ] 同一报价填写调整说明后切页返回或下拉刷新，草稿保留；首发已入库但响应丢失时，不同正文重试应提示冲突，相同正文重试展示服务端保存内容。
  - [ ] 日历进入预约详情取消或结束预约后返回，旧占用及时移除且编辑草稿保留；保存中返回待结果结束后刷新，跨月后“本月”入口正确。
  - [ ] 场景指南进入车辆页后返回重新读取最新内容，已下线指南不再展示旧正文和关联车辆；断网显示内容来源提示。
  - [ ] 交接草稿填写或上传照片后切换取还车阶段，取消保留全部内容；确认期间内容已变化时，旧确认不得清空新草稿。
  - [ ] 交接提交、备注、标签、报价和状态写入期间切页，结果返回来源页后只反馈一次；版本冲突和网络失败仍保留草稿与原始反馈。
  - [ ] 导出交接报告超时后重试，迟到回调不删除新文件；重复导出回收旧文件，损伤说明、缺失值和内容核对状态与原记录一致。
  - [ ] 两个表单页前后切换时，后台保存和卸载不关闭当前页未保存提醒；原生提醒启用或关闭失败后，返回来源页可重新同步。
- [ ] **提交审核**：
  - [ ] 准确勾选小程序所属类目（如“汽车服务 / 汽车租赁与展示”）。
  - [ ] 提供审核员专用测试账号或在备注中说明免登录浏览流程。
- [ ] **灰度发布阶段**：
  - [ ] **Day 1**：全网灰度 10%，持续观察云开发监控面板（函数调用量、错误日志统计、慢查询）。
  - [ ] **Day 2**：若无高危告警，灰度扩大至 30%。
  - [ ] **Day 3**：灰度提升至 100% 全量发布。
- [ ] **回滚应急预案**：
  - [ ] 如遇严重线上阻塞缺陷，微信公众平台后台支持一键“回退至上一发布版本”。
