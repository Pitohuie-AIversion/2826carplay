# WECHAT_REVIEW_AND_PRIVACY.md

## 1. 目的

本文件用于约束小程序在上线前需要考虑的审核、隐私和合规问题。

具体审核规则以微信公众平台当前要求为准。本文只作为项目内部开发约束，不替代正式审核要求。

## 2. 第一版隐私原则

第一版只收集预约所必需的信息：

- 姓名
- 手机号
- 取车日期
- 还车日期
- 城市
- 备注

禁止收集：

- 身份证照片
- 驾驶证照片
- 精确定位
- 通讯录
- 人脸信息
- 与预约无关的个人信息

## 3. 用户授权原则

需要用户主动触发的能力：

- 打电话
- 联系客服
- 分享
- 未来获取手机号
- 未来获取定位

禁止自动获取用户隐私信息。

## 4. 页面内容约束

页面内容应清晰说明：

- 车辆价格以客服确认为准
- 车辆档期以客服确认为准
- 提交预约不代表订单已确认
- 押金、保险、取还车规则需客服确认
- 可信档案中的车况、保险和救援内容仅为运营人员维护的公开摘要，不等同于政府、平台或第三方认证
- 资料缺失、待复核或超过 180 天时必须如实展示对应状态
- 不公开完整保单、行驶证、VIN、发动机号、完整车牌或内部车辆原始记录

## 5. 上线前检查

上线前需要检查：

- 小程序名称是否与页面品牌一致
- 服务类目是否与业务匹配
- 隐私政策是否覆盖实际收集字段
- 客服联系方式是否有效
- 电话号码是否有效
- 页面无诱导分享
- 页面无虚假折扣
- 页面无夸大承诺
- 图片素材拥有使用权限
- 客服、监督和投诉电话真实有效，且页面说明人工处理边界
- 既有车辆可信档案均来自真实资料核对，不批量填充虚构默认文案

## 6. 第一版禁止上线的功能

未完成正式合规准备前，不上线：

- 在线支付
- 押金支付
- 身份证上传
- 驾驶证上传
- 人脸识别
- 精确定位
- 真实订单合同
- 自动库存锁定
- 保险计算
- 违章处理

## 7. 隐私提示文案建议

预约页底部可放：

```text
提交预约即表示您同意我们仅将所填信息用于本次车辆预约沟通。车辆档期、价格、押金及取还车规则以客服最终确认为准。
```

## 8. Phase 14 交接资料边界

- Phase 14 交接照片属于预约服务资料，云存储不公开读取；仅预约本人和具备预约管理权限的顾问可在服务端鉴权后获取短期访问地址。
- 用户的“核对交接记录”仅用于确认页面内容，不构成电子签章、合同签署、自动定损、扣款或维修报价。救援电话只连接人工渠道，不宣传实时调度能力。
- 交接记录纳入个人信息查询导出和归档清理流程；CSV 不包含可长期访问的照片地址，错误与审计日志不得复制照片地址或车况说明正文。
# Phase 15 档期与价格数据说明

- `vehicle_calendar_days` 的确认预约记录只保存预约 ID、车辆 ID、日期和占用类型，不保存 OpenID、姓名、手机号、城市或备注；维修、保留和不可用记录不关联用户。
- `vehicle_availability_blocks` 中的运营原因仅供有预约管理权限的后台查看，用户接口不返回原因、其他预约 ID 或运营人员身份。
- `vehicle_price_rules` 是车辆级公开决策信息，不保存用户身份或单个用户浏览链路；用户只看到所选日期的规则名称和每日参考价。
- `availability_shortage` 与 `price_change_view` 继续沿用匿名分析模型，只保存事件类型、车辆 ID 和服务端时间。
- 取消或完成确认预约会删除活跃日锁；区间状态和审计摘要保留用于排期追溯。审计不复制操作原因正文。
