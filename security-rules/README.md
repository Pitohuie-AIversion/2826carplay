# 生产安全规则

本目录保存云环境 `cloud1-d8gtmns36320e045e` 的生产安全规则基线。规则不会随普通云函数上传自动生效，正式发布前需要在云开发控制台逐项配置并真机复核。

## 数据库

在“文档型数据库 → 集合管理 → 权限管理”中，将 `manifest.json` 列出的每个集合切换为自定义安全规则，并粘贴 `database-deny-client.json`。

项目全部数据库读写均通过云函数完成，因此客户端应禁止直接读取和写入。该规则不会限制云函数服务端和云开发控制台。

## 云存储

在“云存储 → 权限设置 → 自定义安全规则”中粘贴 `storage.json`。

- 只允许客户端读取 `vehicle-images/` 下的车辆展示图片。
- 只允许已登录、非匿名的文件创建者写入或删除自身文件。
- 写入路径必须位于 `vehicle-images/`，单文件不能超过 10 MB。
- 车辆资料云函数仍会校验管理员权限、车辆 ID、目录归属和图片数量。

由于云存储规则本身不支持查询项目的 `roles` 集合，管理员身份仍由上传页面的权限守卫和后续 `vehicleImageUpdate` 云函数共同校验。上线后应同时开启云存储容量告警。

## 云函数

在“云函数 → 权限控制”中粘贴 `functions.json`。该规则拒绝未登录和匿名调用；车辆、预约、隐私、日志等细分权限继续由各云函数服务端校验。

## 生效验证

规则修改后等待 1–3 分钟，再执行：

1. 普通用户无法通过调试器直接读取或写入任一数据库集合。
2. 首页和车辆详情仍可展示 `vehicle-images/` 中的图片。
3. 普通用户不能进入车辆管理上传图片。
4. 管理员可上传不超过 10 MB 的车辆图片，并能设为封面或删除。
5. 未登录或匿名客户端不能调用云函数，正常微信小程序用户流程不受影响。
