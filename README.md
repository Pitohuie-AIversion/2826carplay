一个基于微信小程序原生能力开发的汽车展示与预约咨询 MVP 项目，当前聚焦“高质感车辆展示 + 基础预约沟通”，适合作为产品原型、演示样板和后续业务扩展基础。

## 项目简介

极境车库面向汽车展示与预约咨询场景，当前版本由微信云开发驱动，已完成首页车库展示、分类筛选、车辆详情、预约咨询、我的预约和后台运营管理等核心流程。

该项目当前不是完整租车交易平台，不包含在线支付、押金支付、身份证或驾驶证认证、电子合同和自动库存锁定。

## 功能概览

- 首页车辆展示
- 车辆分类筛选
- 首页支持搜索车型、品牌和车辆标签，并可与分类及“全部状态 / 可预约”组合筛选；搜索和专属顾问入口使用清晰原生图标，关键词可通过圆形关闭图标快速清空，客户侧统一使用可预约、使用中、维护中和已预约状态文案；加载失败、搜索无结果、无可预约车辆、空车库和列表完成均使用对应原生反馈图标，重试、分页、继续搜索、清除搜索与恢复全部状态入口保持一致
- 首页总车源与可预约数量集中保留在车库摘要，状态切换压缩为带原生调节器图标的轻量工具条，减少重复数字和首屏纵向占用；车型分类在小屏设备上提供右侧渐隐提示，切换后自动将当前分类滚入可见区
- 车库、收藏、预约和我的共用底部核心导航，采用统一原生图标、清晰选中态和按压反馈，四个主页面可直接切换；导航使用标准标签组与当前标签语义，选中项同步增强文字字重，品牌徽标不产生重复朗读
- 车库、预约、收藏和我的四个核心页面正文，以及核心导航与车辆详情悬浮操作栏同时适配底部及横向安全区；普通竖屏保持统一基础留白，横屏和侧边刘海设备自动增加安全距离，页面尾部动态预留全面屏手势空间，最后一张卡片不会被吸底操作遮挡
- 车辆详情查看
- 车辆详情统一客户侧状态口径，使用原生放大预览与收藏图标，收藏处理中隐藏心形避免与加载圈叠加并显示稳定状态文案，支持车辆图片全屏预览，并展示提交意向、顾问确认和安排交付三步预约流程
- 车辆详情轮播在图片加载、加载失败或暂无图片时复用极境车库徽标与品牌档案布局；多图浏览显示分段进度与当前位置，单图关闭循环以避免错误滑动暗示；底部预约行动栏同时避开左右及底部安全区
- 车辆详情底部行动栏会根据可预约、已预约、使用中和维护中状态给出对应咨询提示，预约和电话咨询使用对应业务图标；加载失败或车辆不存在时展示品牌空状态，并提供原生重试或返回入口
- 预约咨询表单
- 预约填写页、提交成功页、加载与失败状态统一避让左右及底部安全区；提交处理中显示原生加载圈，将文案切换为“正在提交”并隐藏业务图标和方向箭头，避免多重反馈叠加
- 预约表单实时显示信息完成度和下一项填写提示，并以“联系资料—出行日期—隐私确认”三段状态引导填写；姓名、手机、取还车日期和隐私确认统一标记必填，取车城市明确标记选填，已完成字段使用轻量蓝色描边反馈；隐私同意区扩大勾选与政策链接触控面积，勾选后切换蓝色完成描边并同步辅助状态；资料完整前提交按钮保持不可用，完整后集中确认车型、日期、城市和脱敏联系方式；提交成功页的顾问联系、查看预约及继续浏览操作使用对应原生业务图标，不在本地保存敏感草稿
- 预约日期、取车城市以及车辆新增和编辑表单的选择控件统一使用原生下拉箭头，并提供明确辅助名称；车辆新增与编辑页共享五项必填完成度和下一项提示，五项输入与选择控件声明必填并在完成后显示轻量蓝色描边，车辆身份、展示租赁和内部档案使用对应原生图标，底部吸底提交栏明确显示可提交状态，创建、保存、图片管理、失败重试与返回均使用对应业务图标；车辆图片上传说明使用原生信息图标
- 预约日期、取车城市、车辆类型、注册日期、使用状态、变速箱和燃油类型选择器统一提供轻量按压反馈，触感与输入框和按钮保持一致

上传前优先执行统一发布检查：

```powershell
npm run check:release
```

该命令会依次执行项目结构检查、密钥扫描、主包体积检查和全量测试，任一环节失败都会立即中止。结构检查会核对页面路由、页面必需文件，以及云函数目录与部署清单是否一致；密钥检查会阻止私钥、环境文件和硬编码生产凭据进入仓库；包体检查达到 `1.75 MiB` 时预警，达到 `2 MiB` 时返回失败并列出最大的本地文件。单项排查可使用 `npm run check:structure`、`npm run check:secrets` 或 `npm run check:package`。

联网环境下还应执行 `npm run audit:cloud`。49 个云函数使用相同锁定依赖树，因此该命令审计代表性锁文件并在出现严重级漏洞时失败；当前官方最新版仍会报告来自 CloudBase 上游依赖的高危和中危项，需在每次部署前复核官方 SDK 更新。

## 数据与页面说明

### 数据来源

车辆、预约、收藏、匿名统计、权限、隐私申请和运营配置来自微信云开发：

- `vehicles`：车辆信息
- `bookings`：预约咨询记录
- `favorites`：用户车辆收藏记录
- `analytics_events`：不含 OpenID 和表单内容的行为事件
- `roles`：后台权限
- `app_configs`：运营配置
- `privacy_requests`：个人信息权利申请与处理状态
- `data/categories.js`：首页分类配置
- `data/cars.js`：仅保留为早期示例数据，不参与当前线上主流程

当前分类包括：

- `luxury_sedan`：豪华轿车
- `city_suv`：城市SUV
- `offroad`：硬派越野
- `supercar`：超级跑车
- `commuter_ev`：代步电车
- `pickup`：皮卡

车辆状态字段统一使用：

- `available`：在库
- `reserved`：已预约
- `rented`：已租出
- `maintenance`：维护中

### 页面职责

- `pages/garage/garage`
  - 通过 `garageVehicleList` 读取公开车辆数据
  - 进行分类筛选
  - 展示车辆卡片
  - 跳转详情页
  - 提供电话联系与分享能力
- `pages/car-detail/car-detail`
  - 通过 `vehiclePublicDetail` 按 `carId` 查询单辆车
  - 展示车辆图片、标签、状态和说明
  - 跳转预约页
  - 提供电话联系能力
- `pages/booking/booking`
  - 按 `carId` 读取车辆信息
  - 提供姓名、手机号、取还车日期、城市和备注输入
  - 执行表单校验、隐私确认、重复预约和频率限制
  - 创建预约咨询记录，不创建支付订单
- `pages/mine/mine`
  - 提供我的预约、客服、规则和隐私政策入口
  - 根据服务端权限动态展示管理入口
